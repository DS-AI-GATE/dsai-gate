## <a name="books"></a>Books

Explore these recommended books to enhance your understanding:

- **[Algorithm Design by Jon Kleinberg and Eva Tardos](https://www.pearson.com/en-us/subject-catalog/p/algorithm-design/P200000003264/9780321295354)**  
  Official publisher page. Comprehensive treatment of greedy algorithms, divide-and-conquer (mergesort, quicksort recurrences), and graph algorithms.

- **[Data Structures & Algorithms in Python](https://www.pearson.com/en-us/subject-catalog/p/data-structures-and-algorithms-in-python/P200000003290/9780134855684)** by Michael T. Goodrich, Roberto Tamassia, and Michael H. Goldwasser  
  Official publisher page. Systematic coverage of stacks, queues, linked lists, trees, hash tables, sorting, and searching in Python.

## <a name="course"></a>NPTEL and MOOCs Courses

Course to deepen your knowledge:

- **[Programming, Data Structure and Algorithms using Python, IIT Madras](https://nptel.ac.in/courses/106106145)**: A foundational course by Prof. Madhavan Mukund covering the full syllabus: Python semantics, recursion, search, sorting, and data structures.
- **[MIT OCW 6.006: Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/)**: Excellent lectures on asymptotic analysis, divide-and-conquer, binary search trees, hashing, graph traversals (BFS, DFS), and shortest path algorithms (Dijkstra, Bellman-Ford).
- **[Harvard CS50: Introduction to Programming with Python](https://cs50.harvard.edu/python/2022/)**: Hands-on foundations for Python programming, functions, data structures, and debugging.
- **[IIT Delhi Algorithms Course (COL351)](https://www.cse.iitd.ac.in/~rjaiswal/Teaching/2022/COL351/lectures.html)**: Undergraduate lectures on algorithm design and complexity analysis.

## <a name="practice-problems"></a>Practice Problems

  Curated GATE questions on asymptotic analysis, divide and conquer, searching, sorting, and graph traversals.
